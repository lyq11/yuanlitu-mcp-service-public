# 元狸图 MCP

元狸图 MCP 是面向嘉立创 EDA / EasyEDA 专业版的本地 MCP 工具。它把 EDA 内的原理图能力通过本机白名单 RPC 暴露给 Codex、Claude、Trae 等 MCP Host，让 AI 可以读取、检查并安全修改当前打开的原理图。

这个公开分发仓库提供二进制发布包、部署 Skill 和使用说明。

## 当前版本

最新公开发行版为 **v0.1.35**，包含 Windows x64 MCP 服务端 **v0.1.33** 和 EasyEDA 扩展 **v0.1.35**。

默认连接参数：

- 端口范围：`49640-49649`
- WebSocket 路径：`/yuanlitu-mcp`
- 服务标识：`yuanlitu-mcp`

## 可以做什么

| 功能 | 支持的操作 |
| --- | --- |
| 连接和选图 | 查看连接状态、重新连接、停止连接、设定本机端口。按工程保存主原理图，可在连接窗口随时切换。 |
| 读取与检查 | 查看工程目录和图页，读取整页或指定区域的器件、引脚、导线、网络、标签、属性和文字注释，统计器件清单与图面占用。 |
| 器件与分页 | 搜索 EasyEDA / 立创库，放置、移动、旋转或镜像器件。支持原理图及分页重命名、创建和删除分页，以及在同一原理图内跨页移动器件。 |
| 电气连接 | 连接引脚，创建导线、原生网络标签、跨页端口和电源地标志，设置未连接引脚的 NC 标记。 |
| 属性和文字 | 修改器件属性及显隐，新增说明文字。可先读取并核对旧注释，再精确删除和重建。 |
| 逻辑设计 | 以模块、器件和网络建立草稿，校验并保存、恢复或导出 JSON。可先预览布局和连线，再导入原理图，通过检查点核对中断位置。 |
| 验收与备份 | 执行原理图 DRC，检查图面拥挤、交叉和文字重叠。自动备份默认开启，每个 MCP 会话首次写入前创建原理图副本。 |

跨页移动器件后需要重新接线并清理原页旧线。插件提供的是**原理图**操作，PCB 编辑、走线、过孔和铺铜超出本版范围。

## 在插件里操作

- **显示连接状态** · 检查连接并重连、切换端口、停止连接或切换主原理图。
- **安全与引擎设置** · 管理自动备份及原理图布局、布线引擎偏好。带刚性分组的逻辑设计导入使用元狸图引擎，以保留组内位置。
- **开启/关闭 Debug 日志** · 在 EasyEDA 开发者控制台查看操作信息。分步耗时日志可定位长操作卡在哪一步。
- **功能与版本** · 查看本机版本、能力概览、近期更新及完整版本记录。

## 操作示例

- 「先只读检查显示板，列出悬空引脚和 DRC 问题。」
- 「把原理图按电源、通信、显示拆页，逐针核对跨页连接后再跑 DRC。」
- 「按需求建立逻辑草稿，先预览布局与连线，再导入选定的主原理图。」

## 暂不提供

- PCB 自动布线。
- 信号线自动走线、过孔、铺铜等高风险 PCB 写入能力。
- 云端 AI 请求能力。本工具只负责 MCP 与 EDA 的本地连接；AI 能力由 Codex、Claude、Trae 等 MCP Host 提供。
- 源代码公开分发。公开仓库只发布 exe 和 EasyEDA 扩展包。

## 下载

### 用 Codex 一键部署

在 Codex 发出这条请求，即可使用部署 Skill。

~~~text
请从 https://github.com/lyq11/yuanlitu-mcp-service-public/tree/main/skills/yuanlitu-mcp-deploy 安装并使用 yuanlitu-mcp-deploy Skill，帮我部署元狸图 MCP。
~~~

Skill 支持 Windows x64。它会下载发行包、校验 SHA-256、安装本地服务和扩展文件，并配置 Codex。修改已有配置前会创建备份。安装后，在嘉立创 EDA 专业版的 **高级 → 扩展管理器 → 导入** 中选择 Skill 返回的 `.eext`，然后刷新 MCP 客户端。

也可 [下载 PowerShell 部署脚本](https://raw.githubusercontent.com/lyq11/yuanlitu-mcp-service-public/main/skills/yuanlitu-mcp-deploy/scripts/install.ps1)，保存后从所在目录运行。

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
~~~

为其他 MCP 客户端准备安装文件时，可加 `-ArtifactsOnly`，再使用脚本返回的服务端路径配置客户端。

## 安装步骤

1. 下载 release 中的 `.zip` 或分别下载 `.exe` 与 `.eext`。
2. 解压到固定目录，例如：

   ```text
   C:\Tools\yuanlitu-mcp\
   ```

3. 在嘉立创 EDA / EasyEDA 专业版中安装 `.eext` 扩展。
4. 打开 EDA 工程和原理图页面。
5. 在 MCP Host 中配置 `yuanlitu-mcp.exe`。
6. 重启 MCP Host，或在 Host 中刷新 MCP 连接。
7. 在 EDA 插件菜单中打开「连接状态」，按需重新连接或选择「切换主原理图」。

## Codex 配置

添加到：

```text
C:\Users\<你的用户名>\.codex\config.toml
```

示例：

```toml
[mcp_servers.yuanlitu_easyeda]
command = "C:/Tools/yuanlitu-mcp/yuanlitu-mcp.exe"
args = []
startup_timeout_sec = 20
tool_timeout_sec = 120
```

如果你希望 Codex 对只读工具少询问，可以追加：

```toml
[mcp_servers.yuanlitu_easyeda.tools.easyeda_health]
approval_mode = "approve"

[mcp_servers.yuanlitu_easyeda.tools.schematic_list_pages]
approval_mode = "approve"

[mcp_servers.yuanlitu_easyeda.tools.schematic_inspect_page]
approval_mode = "approve"
```

## 使用建议

- 先让 AI 执行连接检查，再读取当前原理图页面。
- 对写入类操作，建议先让 AI 说明将要修改的区域和器件。
- 大范围修改前，在「连接状态」确认 MCP 选中的主原理图。
- 如果 EDA 插件显示等待连接，检查 MCP Host 是否已启动 `yuanlitu-mcp.exe`，以及端口 `49640-49649` 是否被占用。

## 常见问题

### 是否必须开放源代码？

不必须。当前公开仓库只发布无源码二进制包。需要说明的是，这不是加密或绝对防逆向方案，只是普通用户分发场景下的无源码可执行包。

### 为什么插件本身不内置 AI API Key？

基础版定位是纯 MCP 工具，AI 请求由 MCP Host 负责。这样用户可以直接使用 Codex、Claude、Trae 等现有工具，不需要在 EDA 插件里额外配置 API Key。

### Windows 提示未知发布者怎么办？

当前 exe 未做代码签名，Windows 可能提示未知发布者。正式商业发布建议增加代码签名。

### 中间开发与测试记录

这些条目记录了 v0.1.1 之后的开发过程。标注为公开发行的版本可在 GitHub Releases 下载。

#### v0.1.26 至 v0.1.33（测试构建）

- **v0.1.33** 保存后复核器件位号和值，修复阻容值被覆盖为空的问题。检查电源标志和器件属性文字是否越出图纸。
- **v0.1.32** 将逻辑设计中的器件值和显示设置带入原理图，默认显示位号和已有的值，并检查文字是否与器件或导线重叠。
- **v0.1.31** 统一 EasyEDA 图纸坐标的上下方向，修复电源标志自身的折线引线被误判为碰撞的问题。
- **v0.1.30** 改用完整库器件信息放置元件，明确报告失效器件 ID，并修正断点恢复时对库器件与落图器件的匹配。
- **v0.1.29** 电源和地标志通过短引线避障，导入时检查与器件、导线、网络名和图框说明栏的重叠。
- **v0.1.28** 区分 EasyEDA 为原生电源标志生成的零长度附着线与普通零长度导线，减少可读性误报。
- **v0.1.27** 修复单引脚电源网络悬空，兼容 EasyEDA DRC 的多种返回格式，分别汇总警告和错误。
- **v0.1.26** 支持保存逻辑设计、保留导入检查点和修复未布线器件的位置。改进分组布局与多转弯避障，导入时检查真实引脚、连通性、布局、可读性和 DRC。

#### 连接、导入与安全连线

- **扩展 v0.1.25 / 服务端 v0.1.21** 连接状态窗口改为原地刷新。新增扩展安全设置，默认启用自动备份。布局和布线引擎可分别选择，插件维护工程目录缓存。导入逐页运行 DRC，并核对断点恢复时的器件身份。
- **v0.1.21** 支持建立和导入逻辑原理图。根据引脚所在方向和端口的输入、输出类型确定端口朝向，让端口名称朝器件外侧展开。
- **v0.1.20** 普通导线和引脚连线通过端点接触继承网络，支持在指定位置创建原生网络标签。显式命名导线的高级入口默认关闭。
- **v0.1.19** 创建端口时默认拦截碰撞，诊断模式可显式允许放置并返回碰撞详情。
- **v0.1.18** 优先用引脚朝向识别引脚所在侧，随后参考器件外框。
- **v0.1.17** 移除全局函数追踪，保留用于定位连接和写入问题的 RPC 耗时日志。

#### 分页与主原理图

- **v0.1.14** 分开计算器件本体、可见属性和电气碰撞范围，减少隐藏属性对布线避障的干扰。
- **v0.1.12–v0.1.13** 读取和写入前重试暂时不可用的工程与页面状态，减少切页或保存时的 `boardsArr` 错误。
- **v0.1.11** 按工程选择并保存主原理图，MCP 读取和写入限定在选中的原理图内。新增跨页操作和批量写入的分步耗时日志。
- **v0.1.10** 新建分页后同时核对页面 ID 和页名，避免操作成功时仍返回默认页名。
- **v0.1.8–v0.1.9** 跨页重建时先解析完整库器件。旧器件 ID 失效时，按完全一致的供应商料号查找，并报告替换结果。
- **v0.1.5–v0.1.7** 跨页移动时等目标页准备就绪，删除源器件后再恢复原位号，并报告移动进度。
- **v0.1.4** 按移动数量调整跨页操作超时，减少重复的器件属性写入。
- **v0.1.3** 修复分页已重命名成功，却因页面缓存延迟被误回滚的问题。
- **v0.1.2** 新增分页创建、同一原理图内跨页移动器件和 MCP 端口查询。批量写入合并为一次请求，每个受影响的页面集中保存。
